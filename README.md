
# rosalind.info

Python and R solutions for selected Rosalind bioinformatics problems.

## Quickstart

```bash
git clone https://github.com/stanevvv/rosalind.info.git
cd rosalind.info
````

Run a Python solution:

```bash
python3 <script>.py [input_file]
```

Run an R solution:

```bash
Rscript <script>.R [input_file]
```

Scripts read from `input_file` when provided; otherwise, they read from standard input.
