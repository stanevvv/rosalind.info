# rosalind.info

Python and R solutions for selected [Rosalind](https://rosalind.info/) bioinformatics problems.

## Purpose

This repository is a personal learning project on bioinformatics and algorithmic problem solving in scienctific context.<br>
My approach to each problem is to first learn about the topic - most commonly biology and statistics. Then code the solution with full understanding of the terminology and concepts at hand. 

## Repo Structure

Solutions are organized by Rosalind problem ID under [`problems/`](problems/).<br>
IDs are unique to each problem and are determined by their author.

Each problem directory contains its implementation and, where relevant, problem-specific sample data.

## Quickstart (Unix systems)

```bash
git clone https://github.com/stanevvv/rosalind.info.git
cd rosalind.info
````

Run a Python solution:

```bash
python3 problems/REVC/solution.py
```

Run an R solution:

```bash
Rscript problems/PROT/solution.R
```

See [`problems/README.md`](problems/README.md) for the complete solution index.
